# 📊 매입·매출 마감 대시보드

그로븐(면세)·옐로우브릿지(과세) 두 스토어의 **월 매입·매출 마감 자료를 정리하고
표·차트·대시보드로 보여주는 웹 도구**입니다. 설치가 필요 없고 브라우저에서 바로 동작합니다.

> 🔒 **개인정보 안전** — 올린 통장내역·매출·매입 자료는 **여러분 브라우저 안(localStorage)에만**
> 저장됩니다. 서버로 전송되거나 외부에 올라가지 않습니다.

---

## 무엇을 할 수 있나요?

| 기능 | 설명 |
|------|------|
| 📂 **기존 마감 엑셀 불러오기** | 지금 쓰시던 그로븐/YB 엑셀을 올리면 매출·매입·입출금·송금처를 한 번에 가져옵니다 |
| 🏦 **기업은행 통장내역 자동 정리** | IBK 거래내역 엑셀을 올리면 **입금=매출정산 / 출금=매입·비용**으로 자동 분류 |
| 🧾 **발주서로 매입 정리** | 양식이 매번 달라도 OK — 열을 골라 매핑하면 매입으로 정리 |
| 📈 **대시보드** | KPI 카드 + 월별 추이·채널별 매출·매입 분류·누적손익 차트 |
| 📄 **월 마감 보고서** | 스토어별 매출/매입/입출금 + 재무현황을 엑셀로 다운로드 (인쇄도 가능) |

**모든 표는 요청대로 금액이 큰 것부터(내림차순) 순번이 매겨집니다.**

## 사용법

### 1. 웹에서 바로 열기 (GitHub Pages)
저장소 **Settings → Pages → Source: GitHub Actions** 로 설정하면,
이 브랜치에 푸시될 때마다 자동 배포되어 아래 주소로 접속할 수 있습니다.

```
https://groven8990-crypto.github.io/sales-purchase/
```

### 2. 내 PC에서 열기
저장소를 내려받아 `index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
(인터넷 연결 없이도 동작 — 라이브러리가 `vendor/` 폴더에 포함되어 있습니다)

## 처음 시작하기

1. 상단에서 **스토어**(통합 / 그로븐 / 옐로우브릿지)와 **연·월**을 고릅니다.
2. **📂 기존 마감 엑셀 불러오기**로 지금 쓰던 파일을 올려 데이터를 채웁니다.
3. 매달 **🏦 통장내역**과 **🧾 발주서**를 올려 자동 정리합니다.
4. **📄 마감 보고서**에서 엑셀을 다운로드하거나 인쇄합니다.

> 💡 데이터를 다른 PC로 옮기거나 백업하려면 **⚙️ 데이터·설정 → 전체 백업(JSON)** 을 이용하세요.

## 기업은행 통장내역 자동 분류 규칙

입금/출금은 금액 위치로 먼저 구분하고, 거래처·적요 키워드로 분류합니다.

- **입금** → 매출 정산 (네이버파이낸셜→네이버, 카카오→카카오톡, 쿠팡페이→쿠팡, 11번가, 지마켓, 옥션 …)
- **출금** → 매입·비용 (임대료/광고비/수수료/도매꾹 등 키워드, 송금처 마스터로 은행·계좌 자동 매칭)

> 자동 분류가 100%는 아니므로, 업로드 미리보기에서 분류를 직접 수정한 뒤 추가할 수 있습니다.
> **기업은행 거래내역 엑셀 샘플을 한 번 보내주시면 컬럼 인식을 더 정확하게 맞춰드립니다.**

## 폴더 구조

```
index.html          화면 구성
css/styles.css       스타일
js/store.js          데이터 모델 + 브라우저 저장
js/parsers.js        엑셀/통장/발주서 읽기·자동정리
js/dashboard.js      KPI·차트
js/report.js         엑셀 보고서 생성
js/modals.js         업로드/미리보기 대화상자
js/app.js            화면 전환·표
vendor/              SheetJS, Chart.js (오프라인 포함)
```

- **증빙**: 세금계산서, 계산서, 현금영수증, 카드내역서, 고지서, 영수증, 통장입금증, 현금, 기타
- **매출 채널**: 쿠팡, 네이버, 11번가, 지마켓, 옥션, 카카오톡, 톡딜 등
